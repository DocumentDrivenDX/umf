Install 0.10.13

Python

Use Python 3.11–3.14. Wheels are available for Linux x86-64 and arm64 (glibc 2.34+) and macOS arm64.

python -m pip install umf-core==0.10.13 \
  umf-codegen==0.10.13 umf-access==0.10.13
Python package guide

Node, Bun and browsers

Download the SDK archive for Linux x86-64, Linux arm64 or macOS arm64. Install the local archive as @umf/core. This example uses macOS arm64. For the web, use the bundled @umf/core/runtime/wasm entry.

npm install ./umf-sdk-0.10.13-macos-aarch64.tgz
SDK archives · Native and WASM setup

CLI and Rust

Download and unpack the CLI archive for your OS and architecture. For Rust, add the published crate from crates.io.

cargo add umf-core@=0.10.13

Read, validate and write a document

from umf import read_document, validate_document, write_document

document = read_document("""
umf: "0.10.0"
id: orders
vocabularies: {}
modules: []
""", format="yaml")
result = validate_document(document)
assert result.valid and result.complete
print(write_document(document, format="json"))

Validation reports both validity and completeness. If the registry cannot interpret an extension, it can preserve the content and report partial understanding.
