# Access, dashboards and domain packs

Metadata consumers choose a bounded view while keeping the source context needed to interpret it. UMF owns portable schemas; hosts own execution.

The access extension describes generated Python models, typed declarations and catalog/runtime requirements. Installed native cohorts and reviewed PostgreSQL reporting each have scoped evidence. Temporal qualification, engine adoption and managed services remain separate.

Dashboard metadata describes presentation intent without requiring a UI engine. Domain packs connect schemas, domain types, source provenance, rights and trusted loader declarations. Reading a pack never fetches data or runs a loader. The existing Schemas browser is the independently released domain-model inspector.
