# DDD is an optional semantic extension

Domain-driven design adds authored entity/value distinctions, aggregates, domain events, services, repositories, bounded contexts and context maps through umf.ddd.

These declarations do not make DDD the governing worldview of UMF. Storage and compute vocabularies may express competing meanings without being rewritten into DDD terms. Opaque invariants and asserted equivalence remain retained declarations, not executed rules or proofs.

Use the extension schema to inspect its cases and scopes. Directed DDD generators have target-specific limits and retained-source reports; their output does not execute a service or database migration.
