# Frame

The product vision defines what UMF is for. The PRD owns functional
requirements and the cross-cutting requirements govern preservation,
compatibility, evidence, security and runtime boundaries. Project concerns
map those requirements to downstream work.

- [Product vision](../00-discover/product-vision.md)
- [Product requirements](prd.md)
- [Cross-cutting requirements](cross-cutting-requirements.md)
- [Project concerns](concerns.md)

Features and user stories define individual capabilities. The repository
roadmap tracks open work. See the [roadmap](../../../ROADMAP.md).
