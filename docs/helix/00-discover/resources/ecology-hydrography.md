# USGS hydrography frameworks

## Source

- URL: [USGS hydrography frameworks](https://www.usgs.gov/3d-hydrography-program/access-3dhp-data-products)
- Accessed: 2026-10-08. Release/snapshot pin and selected dataset reuse terms remain design inputs unless a release is named below.

## Summary

USGS hydrography products describe surface-water features and provide the geographic foundation for stream-network analysis.

## Relevant Findings

USGS states that it shifted from maintaining NHD, WBD and NHDPlus HR to 3D Hydrography Program production in 2024. Select and retain the actual product/version used rather than labeling every framework simply current hydrography.
