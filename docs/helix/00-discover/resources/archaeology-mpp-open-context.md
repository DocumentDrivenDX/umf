The Madaba Plains Project–ʿUmayri Open Context publication provides machine-readable project metadata and references to published archaeological records.

## Relevant Findings

Inspected project JSON declares CC BY 4.0, DOI 10.6078/M7W37TGB and a linked lithics data table. Its abstract describes artifact and paleozoological/paleobotanical work. Project metadata alone does not enumerate or verify every specialist table or media file.
