# GBIF biodiversity reuse and sensitive locations

## Source

- URL: [GBIF biodiversity reuse and sensitive locations](https://ipt.gbif.org/manual/en/ipt/latest/applying-license)
- Accessed: 2026-10-08. Release/snapshot pin and selected dataset reuse terms remain design inputs unless a release is named below.

## Summary

The Global Biodiversity Information Facility (GBIF) documents dataset licensing for biodiversity publication and reuse.

## Relevant Findings

Dataset licenses vary, including CC0, attribution and noncommercial variants. Select a redistributable fixture set with attribution recorded; do not infer uniform permission from public access. Sensitive location generalization must be retained as a transformation.

## HELIX Usage

Grounds FEAT-024, US-075 and SD-024 ecology/water-management planning. Source vocabulary/code extraction must use an archived release and explicit mapping tooling; no live vocabulary list is copied into these plans.

## Authority Boundary

Biodiversity fixture publication. The selected publisher dataset and its terms govern reuse, not a blanket open-data label.

Sensitive-location guidance: [GBIF generalization best practices](https://docs.gbif.org/sensitive-species-best-practices/master/en/). The pilot must retain the publisher's supplied generalization, uncertainty and withheld-data metadata.
