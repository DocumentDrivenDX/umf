# OGC SensorThings observation model

## Source

- URL: [OGC SensorThings observation model](https://docs.ogc.org/is/18-088/18-088.html)
- Accessed: 2026-10-08. Release/snapshot pin and selected dataset reuse terms remain design inputs unless a release is named below.

## Summary

The Open Geospatial Consortium (OGC) SensorThings API Part 1: Sensing 1.1 models sensors, datastreams, observed properties, observations and features of interest.

## Relevant Findings

An observation links a property of a feature to a procedure and event time; result time is distinct. It provides a useful observation reference, but a SensorThings-shaped table does not establish API conformance.

## HELIX Usage

Grounds FEAT-024, US-075 and SD-024 ecology/water-management planning. Source vocabulary/code extraction must use an archived release and explicit mapping tooling; no live vocabulary list is copied into these plans.

## Authority Boundary

Shared observation model proposal. UMF retains native profiles and does not require every source to become a SensorThings service.
