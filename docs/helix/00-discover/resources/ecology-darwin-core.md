# Darwin Core biodiversity vocabulary

## Source

- URL: [Darwin Core biodiversity vocabulary](https://dwc.tdwg.org/terms/)
- Accessed: 2026-10-08. Release/snapshot pin and selected dataset reuse terms remain design inputs unless a release is named below.

## Summary

Biodiversity Information Standards (TDWG) Darwin Core defines vocabulary for biodiversity events, occurrences, organisms, taxa and measurements.

## Relevant Findings

Event sampling effort and occurrence detection/non-detection have explicit meanings. Preserve taxonomic identification and source concept references instead of treating a name as immutable species identity. This living vocabulary needs a pinned term-list revision.

## HELIX Usage

Grounds FEAT-024, US-075 and SD-024 ecology/water-management planning. Source vocabulary/code extraction must use an archived release and explicit mapping tooling; no live vocabulary list is copied into these plans.

## Authority Boundary

Biodiversity survey and entomology profiles. Darwin Core does not make opportunistic occurrences quantitative abundance estimates.
