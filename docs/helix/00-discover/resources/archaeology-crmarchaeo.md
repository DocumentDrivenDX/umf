# CRMarchaeo excavation model

## Source

- URL: [CRMarchaeo excavation model](https://cidoc-crm.org/extensions/crmarchaeo/html/CRMarchaeo_v2.1.html)
- Accessed: 2026-10-08. Selected record snapshots and media terms require inventory.

## Summary

CRMarchaeo is an extension of the CIDOC Conceptual Reference Model for archaeological excavation documentation.

## Relevant Findings

The inspected 2.1 declaration references CIDOC CRM 7.1.2 and CRMsci 2.0. It distinguishes excavation activities and stratigraphic entities and emphasizes observation versus subsequent interpretation. The version page describes proposal status.

## HELIX Usage

Grounds FEAT-025, US-076 and SD-025. Extract native vocabulary and identifiers from pinned source bytes through declared mapping tooling, not from remembered labels.

## Authority Boundary

Conceptual mapping reference for FEAT-025/SD-025, not a mandatory UMF worldview or an implemented native-equivalence claim.
