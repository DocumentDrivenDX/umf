# Madaba Plains Project excavation manual

## Source

- URL: [Madaba Plains Project excavation manual](https://madabaplains.org/umayri/excavation-manual.htm)
- Accessed: 2026-10-08. Selected record snapshots and media terms require inventory.

## Summary

The Madaba Plains Project excavation manual documents the project's field recording terminology and methods.

## Relevant Findings

The manual distinguishes square/locus recording, top plans, section drawings, photographs and subsequent interpretation. It discusses pottery readings and specialists. The visible manual is a source-specific historical method description, not universal archaeological schema authority.

## HELIX Usage

Grounds FEAT-025, US-076 and SD-025. Extract native vocabulary and identifiers from pinned source bytes through declared mapping tooling, not from remembered labels.

## Authority Boundary

Native terminology and evidence relationships. Preserve project forms/IDs without imposing the same excavation method on unrelated packs.
