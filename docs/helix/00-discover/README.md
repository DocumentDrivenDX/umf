# Discover

The [Praxis ontology access request](praxis-ontology-access-input.md) informs
[generated ontology access](../01-frame/features/FEAT-033-generated-ontology-access.md).
The owner's subsequent direction targets the latest UMF directly, without
compatibility selection or a second access model.

Research the problem, audience, and existing solutions; use that evidence
to write `product-vision.md`.

The [product vision](product-vision.md) is drafted from the owner's supplied
direction: schema interchange with native fidelity, extensibility, and
explicit translation limits. [Discovery input](vision-input.md) preserves
the detailed product surface, boundaries, and open decisions.

[Interoperability source notes](interoperability-sources.md) record a focused
check of LinkML, JSON Schema testing, Protobuf native tools, and TypeSpec.
The [competitive analysis](competitive-analysis.md) covers Palantir Foundry,
OntoBricks, Stardog, and related modeling/semantic platforms. Comparative execution,
TableSpec inspection, and audience validation remain pending. The vision is a draft; integration support has not been established.
