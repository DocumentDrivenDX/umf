The intended architecture is a design/build-time portable TypeScript compiler in
UMF, developed with Bun and verified in real Chromium. It generates ordinary
Python source: separate Pydantic row/create/patch/key/named-projection models,
exact codecs, PostgreSQL SQLAlchemy/Core declarations and Spark/Delta/catalog
proposals. Generated applications need no compiler or JavaScript runtime. The
initial package policy stays unchanged; helpers are generated local source.

Connections, sessions, migrations and execution remain consumer-owned. Weft owns
logical SQL lowering. Truss must retain fixed generic storage and protected
transaction/mutation/journal/feed behavior. Ashlar must retain immutable full
UUID/version publication vectors, resolver/pin custody, fencing and source/ACK
protocols. Source generation alone confers no execution authority.
