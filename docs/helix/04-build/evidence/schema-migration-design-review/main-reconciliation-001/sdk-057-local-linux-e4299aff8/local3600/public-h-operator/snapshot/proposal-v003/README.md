# SDK public-H local Docker operator proposal

This is the third outside-repository operator proposal. It is not run and is not a public-H acceptance claim. Read `PLAN.md` for exact scope, mount policy and limits; `run_public_h_docker.py` is the proposed host launcher. The selected image and reader are pinned in `source-identities.json`; `integrity-manifest.json` covers every regular file in this proposal except itself. Proposals v001 and v002 remain preserved at `/private/tmp/sdk-057-local3600-public-h-operator-proposal001/` and `/private/tmp/sdk-057-local3600-public-h-operator-proposal002/`; neither is overwritten.

The input packet is currently `HELD` and the D5 result plus immutable release identity/assets are not complete. The launcher is intentionally fail-closed: it refuses before Docker if the packet is not `READY`, a field remains held, the reader hash differs from the packet, the image identity is wrong, or any required physical root is unavailable. No Docker image inspection, container run, CI dispatch or Git operation was performed while preparing this proposal. Static AST parsing was the only code check on this launcher; no tests or runtime execution were performed. This v003 source-only correction preserves v002 protections and closes outer-log custody: flush/fsync/close errors are recorded as failures, and a pass requires both physical captures to be regular files with retained sizes and complete-stream hash equality when untruncated. The original seven commands and all reader caps remain unchanged. It is awaiting Sol source review.

The reader's seven proof commands and original H caps remain unchanged. Any later run must use only exact read-only input mounts, the single unique writable output mount, and the pinned Ubuntu 24.04.5 Linux/amd64 image. Its runtime remains OrbStack/Darwin aarch64 emulation; it cannot be described as native Linux or hosted evidence.
