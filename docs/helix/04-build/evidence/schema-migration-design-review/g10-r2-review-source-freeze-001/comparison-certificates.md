# Compiler-private comparison certificates source contract001

Pure compiler metadata, NOT native capabilities. None is serialized into author
options, public plan/discovery, ROOT/host receipts or package public exports.
An opaque/branded compiler object never proves native origin, availability, time,
holds, population or COMMIT. Original fixed host/provider authority is separate.

## One full-input context and exact original handles

createR2ReviewContext takes ONLY the actual previous|null, desired bundle,
complete explicit original history and closed marker-free selector2. Validate
untrusted shapes before property access; preserve located public error boundary.
Snapshot full original canonical inputs once and retain raw source bytes. Verify
bundles using their exact original versions; preserve authored Unicode/finite
JSON numbers/unknown extensions under original source rules, not native-control
ASCII/safe-int coercion. Root owns exact history member bytes and preceding
execution context; cache may index by hash but hits require exact original scope/
member equality. No caller callback/native lookup/verifier/effect hook.

WholeArchiveHandle derives from the exact original five materials, full supplied
ref and verified history: source/config/bundle/retirement plan/source-meaning/
original identities/domains all match. FieldArchiveHandle derives COMPLETE
original Field retirement source/config/plan from actual G05 archiveSources and
verified original history. Do not compile a Field archive source using an assumed
current config to erase historical differences. Missing original plan/context
or unsupported original verifier refuses; no hidden I/O or digest-only fallback.
Whole/Field handles index retained original bytes, never reconstructed snippets.

## Fixed private certificates

WholeComparisonCertificate retains SAME root context identity, actual restore
intent index/table/Record/ref, WholeArchiveHandle and desired source handle,
complete original captured stored-Field set/order/domain comparison, exact
selected G05 additional-Field exception set, admitted subject delta list and
closure coverage. Desired stored set must equal original whole set UNION that
explicit exception, no convenience baseline. Full unrelated source remains in
root context, no filtered/fake source is passed to a compiler.

FieldComparisonCertificate retains SAME context, actual restoration index/table/
Field/original G05 archive, exact null-or-lineage selection, FieldArchiveHandle,
desired source handle, original semantic/value domain correspondence, actual
current/same-plan population CATALOG selector and admitted default/requiredness
deltas. Catalog is source-only metadata: actual native UUID partition/proofs are
not compiler-issued. For same-plan fills use the compiler-owned intermediate
whole prefix; no predicted token/OID or fake before deployment. Old same-carrier
G05 and both lineage target modes remain distinct actual selection branches.

ClosureCoverage is an internal indexed set of every original affected declaration/
subject/edge/unknown source item, its original handle/path and disposition:
unchanged|exact-admitted-change|selected-component. Every item must be covered;
unsupported changed meaning produces a located refusal before any plan. No
blanket 'ignore rest' normalizer, unknown-extension pruning or raw targetCatalog
assignment. Exact old/new constructors and full inputs remain auditable.

ReviewClaim retains original Candidate exact bytes, originating certificate,
actual selection index/source paths, and compiler-derived logical owning group.
Primary/effects companions get one joint source/effect claim; separate current-
source and archived-source comparisons remain independently claimed. The group
is derived from actual selected component/effect graph, not an author group ID
or a caller-provided 'verified' flag. The map is keyed by exact full marker and
source identity, with collision/conflicting path/domain refusal. A matching ID
or object brand alone cannot create ownership.

## Compile consumption and actual lowering

All C comes from local original source constructors. Before lowering, require
reviewedChanges EXACT ordered C stripped to five keys. Derive required defaults
from source A=selected Field archive, B=whole archive excludingA, C=current
retained excludingA/B. Compile then requires exactly one actual defaultChanges
selector per real default delta, none for unchanged; claim it once in SAME group.
A/B default is installed by restoration once, never passed as old existing-
carrier G03 compilation. A new future default never fills retained original NULL
or new-instance population; only the explicit scoped G05 program can fill new IDs.

Lowerers consume genuine SAME-context private certificates/claims created by
fixed module constructors. Do not expose certificate factories or inject them
through public compile options. Shared local G02/G03/G05 semantic/effect leaves
must retain standalone exact validation/bytes; no wholesale legacy marker list
or invented before source. Unclaimed marker/selector, unsupported closure,
wrong-context certificate or duplicate physical effect blocks compilation.
Source certificates grant no backend dispatch: host later verifies source/native/
current-original correspondence and original authority on actual held session.

## Bounds and allocation rules

Use indexed original identities/edges, no all-table cross products. Retain full
original bytes once, private certificates reference SAME immutable handles rather
than clone archives per subject. Charge the original<=96MiB external context,
24MiB history/plan, 64MiB whole material aggregate, G05 tighter sources/options,
2048 Candidate count and original depth/node/ID limits before copying/retaining.
Charge each new Candidate canonical byte length before append, including full
values/paths, and enforce final24MiB complete plan after review/digest. Merge exact
duplicates only under original path/full-value rules; never truncate to fit.
Count every source/edge traversal/canonicalization in a finite root work meter.
Proposed NEW review-only ceiling is1000000 such units and99999 retained subject
slots per root; it is additive for this unadopted .2 compiler subset, never a host
budget/grant reset or claim all other maxima simultaneously fit. These two new
static bounds require explicit peer agreement and disclosure in actual compiler
profile docs before adoption. Overflow is located refusal, no partial result.
Actual memory overhead/runtime/recursive-history behavior needs qualification;
canonical byte accounting does not assert an OS heap hard limit.
