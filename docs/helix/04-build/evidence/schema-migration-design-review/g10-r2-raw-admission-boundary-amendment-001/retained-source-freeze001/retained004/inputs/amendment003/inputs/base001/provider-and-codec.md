## Exact private codec and count metric

The proof stream literal is `umf.table-native-value-stream/0.1` encoded ASCII then one NUL byte. All framing integers unsigned big-endian, checked before arithmetic/allocation. Stream is magic || u32(headerByteLength) || header || u32(rowCount) || rowFrames. Header<=1MiB. StreamBytes is the EXACT number of all those octets, not a heap/WAL size estimate and not G04/G05's old canonical-text metric.

Rows strictly ascending UUID raw16 bytes (fixed native uuid_send output, independently qualify order against pg UUID comparator), unique and exactly the captured live set. Each frame is uuid16 || u64(captured_revision) || valueFrames for every ordered column. Revision positive native int8<=9223372036854775807; no JS-number transport. A valueFrame is tag:u8 || u64(payloadLength) || payload. NULL uses tag0,length0,no bytes; non-NULL uses tag1 and actual byte length, permitting empty text length0. No other tag. Tags/length/count/field order/complete termination are part of digest/count; no trailing bytes, duplicate UUIDs or partial frame accepted. RowCount equals header and exact captured native set, not cursor.rowcount alone.

Non-NULL payload is EXACT selected qualified `pg_catalog.int2send(value)`, `int4send`, `int8send`, `uuid_send`, `boolsend`, `date_send`, `timestamptz_send`, `numeric_send` or `textsend` matching original native type/typmod and qualified actual builtin function OID/signature. This is a version-bound native send representation, NOT a portable cross-version backup format. Native finite/domain guards precede send and any host adaptation. Verify function identity/ownership/namespace/actual PG build, UTF8/server settings and immutable driver bytea decoder. Host accepts exact bytes only, never a printed bytea string, memoryview coercion or Decimal/datetime/float value reconstruction. Restore reuses the ORIGINAL archive header/order and native archived captured_revision as framing reference, extracting the actual current target values by original mapped Field/UUID.
