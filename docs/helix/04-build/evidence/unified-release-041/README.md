# UMF SDK 0.4.1 release

Owner requested releases for the unified UMF 0.10 API and compiler changes on
2026-10-18. SDK version 0.4.1 includes host wheel 0.1.0.dev1; Weft 0.4.44 is
released separately. Unchanged core Python and schema-browser distributions
retain their versions.

Release checks include the SDK archive build and installed public generator
smoke test, TypeScript typechecks, compiler/Python/generated-client boundaries,
new generation and shared graph tests, real Chromium parity, installed host
wheel tests and retained scoped native execution evidence. Publication assets
include exact source and SHA-256 delivery metadata. Hosted Pages publication and
release retrieval are verified before completion. See the release delivery
receipt for observed outcomes; no full repository test-suite claim is inferred.

The unpublished SDK 0.4.0 and Weft 0.4.43 candidates retained their original
tags after hosted gates exposed browser synchronization and a newly declared
compiler capability in an older output digest. Release fixes are recorded in
the successor source; those tags are not rewritten or represented as published.
