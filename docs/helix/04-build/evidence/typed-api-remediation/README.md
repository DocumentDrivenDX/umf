## Attempts and limitations

The first full focused run caught stale cancellation and namespace expectations
and an in-flight helper-name test. The tests were corrected to the amended
contract, rather than adding a false PascalCase reservation. A default5s test
timeout also hit local build contention; the final focused run uses15s per test.
All final focused tests pass. Initial generated-source failure output is retained
as a compact failure summary; it is not a passing gate.
The last reversed/resumed settlement additions pass in the separate
[targeted adoption log](adoption-final.log); no production source changed after
the complete focused run.

The first wheel build could not write the default cache inside the sandbox; the
second offline temporary cache lacked hatchling1.27.0. Building with the existing
cache under approved escalation succeeded, as did the pinned-dependency build.
The fresh installed environment contains only the new wheel and mini-racer0.14.1.
An initial core pytest replay against an older local environment reported one
generated-schema fingerprint mismatch (165 passed). Rebuilding/installing the
current wheel into a new environment resolved that environment mismatch; all166
tests pass. No core validation assertion or schema was weakened.

The corrected Weft API exposed two stale native fixture assumptions. The cursor
test now proves unrelated membership keeps the cursor valid and a declared group
MEMBER edge invalidates it, retaining disabled INHERIT/SET edges. Privileged
outcome-table RLS/column/grant drift is checked through the public full diagnostic
API, with exact CatalogError classification and restoration in finally. Ordinary
recovery then succeeds. Ordinary forged-receipt, other-principal isolation,
concurrency and cancellation assertions remain. This follows CONTRACT-079/081's
explicit diagnostic versus ordinary-admission boundary; no production gate was
relaxed or full catalog scan added per call. Sol reviewed both corrections.
The temporary installed-package diagnostic edit was restored before passing
native runs, and the owned disposable PostgreSQL cluster was stopped afterward.

The complete repository test suite was not run. Portable synthetic hosts do not
qualify graph-write/2 production execution, durable host replay, authorization or
the full Linux architecture/interpreter installation matrix. Native table checks
have their own driver/source pins and must be read separately.
