# R5 Python semantic-value callback slice

This is an opt-in additive Python facade over the Rust semantic-value wire. The prior Python root API had no semantic value registry or validator callback; the semantic predecessor is pinned in `frozen-predecessor.json` and points to the separately frozen TypeScript v3 packet.

`SemanticTypeRegistry.register(reference, definition, validator, protocol="cooperative-v1")` admits the exact reference and copied object definition in Rust before retaining a caller-owned callable. No document content can load or select executable code. Callbacks are synchronous and trusted. They receive copied `(value, definition, SemanticValidatorContextV1)` arguments; `context.report_work(nonnegative_safe_integer)` charges the same Rust `Context` after the callback exits, including when it throws. The engine cannot preempt a callback that does not cooperate. Reentrant calls create nested native invocations and are covered by a focused test.

Ordinary callback exceptions and malformed JSON results produce the Rust semantic-unknown mapping. Callback-raised `UmfCoreError` values do not acquire engine-control provenance. Only the exact fault instance created by `report_work`, result-frame admission, or the native invocation's actual cancellation, deadline, meter, or work controls can produce terminal host-control errors. Callback output serialization has a 1,048,576-unit response-frame budget. Input/output JSON strings preserve UTF-16 code units, including lone surrogates.

The current facade rebuilds the invocation registry from caller-owned entries per call. Large-registry scaling has not been qualified against the TypeScript `Map` implementation. Aggregate checks validate the current source and then recompute it in Rust; duplicate aggregate validation work remains. This slice does not add WASM support, persistent native registry handles, hard callback preemption, or a default package route.

Evidence cohort: CPython 3.11.17, Rust 1.90.0, PyO3 0.23.5, installed `umf-core` abi3 wheel. Rebuild with `uv build --wheel --directory python --out-dir <temporary-directory>` under the pinned toolchain; install the resulting wheel into a clean CPython 3.11 target and run `python -m pytest -q -p no:cacheprovider python/tests/test_rust_semantic_types.py` with that target on `PYTHONPATH`. The exact packet/artifact hashes and replay command are in `receipt.json`.
