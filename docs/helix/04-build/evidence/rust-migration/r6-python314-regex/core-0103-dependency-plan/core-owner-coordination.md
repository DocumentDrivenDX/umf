# Core Python 3.14 regex profile coordination (2026-10-26)

The published Core 0.10.2 assets are immutable. The Mac CPython 3.14 wheel failure is a real profile refusal, not an ABI/import failure: the installed Core release has no `PythonReVersion::V3_14`, while the PyO3 Document path selects the actual interpreter minor. Do not alias 3.14 to 3.13 or bypass that refusal.

A bounded implementation already exists on the Rust migration branch: commit `f4a410c05` (`Add bounded CPython 3.14 regex profile to Rust core`) adds `V3_14` in `crates/umf-core/src/python_regex.rs`, Unicode 16 versioned tables and names, `\\z`, and the 3.14 empty-input `\\B` behavior. The current branch's `from_minor` accepts 11–14 and rejects 15+. The R6 evidence at `docs/helix/04-build/evidence/rust-migration/r6-python314-regex/README.md` reports a 412-row CPython oracle, 15 focused Rust tests, and six source-tree PyO3 assertions on CPython 3.14. It explicitly does not claim installed wheels, other platforms, or broad regex parity. Retain existing 3.11–3.13 behavior and future-minor refusal.

Core ownership path: review and integrate the bounded 3.14 source implementation and its generated Unicode/name provenance into the Core release branch, with source/contract closure and independent review. If any current Core branch diverges, reconcile deliberately; do not copy only the enum arm or tables. A new Core patch/minor release containing this change is required before an installed-wheel migration adoption gate can pass; 0.10.2 cannot be retroactively qualified for 3.14. Update dependent pins to that new release only after its artifacts are published and verified.

Required qualification: regenerate/verify Unicode 16 and CPython 3.14 character-name sources; run exact 3.11–3.14 parser, fold/class, `\\z`, `\\B`, group-name and version-refusal corpora against independent CPython oracles; preserve 3.11–3.13 regressions. Build public Core wheels for the original Linux/Mac 3.11/3.14 four-cell matrix, install each exact artifact in clean environments, and rerun the original offline-mirror native Document read/write roundtrip plus the public installed package gates. Keep the failing Mac 3.14 log as baseline evidence. Treat local source-tree/overlay checks as supporting evidence only, not release qualification.

This is a release dependency for the Rust migration's full-port goal, not a change to the already published Core 0.10.2 artifacts. No new runtime implementation or publication is authorized by this coordination note.
