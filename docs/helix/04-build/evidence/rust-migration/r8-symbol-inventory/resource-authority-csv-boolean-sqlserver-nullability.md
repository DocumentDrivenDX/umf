# R8 resource authority: CSV Boolean and SQL Server nullability

## Scope

This source review resolves two JSON resources that were `authority-unresolved`
in the captured R8 ledger. The CSV Boolean operation schema has direct
authorship history under CONTRACT-053. The SQL Server nullability native
evidence schema has an exact current single-output writer under US-041 and
CONTRACT-040. Both resources remain ordinary package data; neither result
qualifies installed archive bytes or retires TypeScript routes.

`spec/core/csv-boolean-lexical-operation.schema.json` was added with the
explicit lexical conversion profile in commit

`1c07d500c8dd6732ce814bdfb04a532a8df313c0df188f369faf7fcf0b2b85b0` at that
revision. Commit `8706814a9605d7325eef32a5df3d05696de00b62` updated its core
reference to 0.10.0; that revision and the current file both hash to
`6548b442849a2a1246ea860ca5be22eecd98596c571d9c0b74ce1eba7780b791`.
The schema is not generated by a current exact writer, so ledger authority is
`authored-authority-known`, not generated.

The pinned closure covers CONTRACT-053, the current operation consumer and
focused tests, the browser harness, public export, SDK build and archive
packaging rules. The package build copies `spec/` to `dist/spec`; the SDK
archive route is `package/dist/spec/core/csv-boolean-lexical-operation.schema.json`.
Installed archive bytes remain unqualified.

## SQL Server nullability native evidence schema

`spec/extensions/sqlserver-nullability/native.schema.json` is emitted by the
self-contained Bun writer
`scripts/core-ideals/nullability-sqlserver-evidence-schema.ts`. The schema was
introduced alongside that writer in commit `6c280b4fd22c3ffec09cec60ea915d863ccd6b4a`;
the added blob, current file, and isolated current-writer output all hash to
`056ef90d9739962b91b5987a3a6fcfd10fd397329494a5e51b06bcc004c78df0`.
The writer source hash is
`b56b2eadb48baa22009efa3dd28b8ec5e4cd885dd7ec973796c74bc81a324a43`.
It has no schema-file inputs. Its output is generated data, so ledger authority
is `generated-authority-known`.

The test runs the writer from a temporary project copy and compares its bytes
with the checked-in schema. A negative control changes the writer-owned title
and confirms the output no longer matches. The closure pins CONTRACT-040,
TD-041, US-041 AC2 and AC6, the consumer, focused test, public export, and SDK
build/archive rules. The package route is
`package/dist/spec/extensions/sqlserver-nullability/native.schema.json`;
installed archive bytes remain unqualified.
