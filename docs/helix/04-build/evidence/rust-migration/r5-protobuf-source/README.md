# R5 Protobuf source import prepare/finish

This opt-in Rust core slice validates and copies a source request, then invokes
an explicitly supplied trusted compiler capability. The compiler receives an
immutable borrow of a separate request snapshot and the same cooperative
`Context`; the core does not discover a compiler or start a process. A
noncooperative compiler capability is refused. Compiler identity and the
4,000,000-byte descriptor-set bound are checked before descriptor import.
Final document inspection preserves the original source archive and continues
to report `PROTOBUF_COMPILER_REQUIRED`; validation remains incomplete.

The frozen TypeScript predecessor observation is
[`predecessor.json`](predecessor.json), generated by
[`predecessor-capture.ts`](predecessor-capture.ts). It records the successful
document/archive shape and refusal envelopes for unsafe numbers, shape-before-
unknown ordering, unknown-before-field ordering, invalid fields/roots, duplicate
roots, a 700,000-NUL source, compiler error, empty identity, malformed compiler
bytes, and unknown payload/source-archive export. All TypeScript, contract,
design, native-compiler, fixture, and oracle inputs are SHA-256 bound in the JSON
file. The capture stub returns an empty descriptor set and identifies itself as
`capture-compiler/1`; it does not claim compiler acceptance. The frozen capture
was emitted by Bun 1.4.3 with Node 26.3.0. Capture script SHA-256 is
`03b8fd89d9ef1fbba9cde8996d7edcd3fb724d70344bbc7af96ad3ad22eb480c`; output
SHA-256 is `ffd9076d232923f7fe29bbdef125585ab355cd96f3c3255a8d40e2387001b7bc`.

The frozen `tests/protobuf/source.test.ts` predecessor invokes its native
source corpus checks, protoc comparison, and Python source/behavior oracles. An
attempted run reached the final report write but failed with `EPERM` when the
test attempted to write the tracked fixture report in the shared worktree; this
is not recorded as a passing native-oracle run. The standalone predecessor
capture script writes only to stdout and can be rerun with
`bun docs/helix/04-build/evidence/rust-migration/r5-protobuf-source/predecessor-capture.ts`.

The Rust implementation and regression tests are
`crates/umf-core/src/protobuf_source.rs` and
`crates/umf-core/tests/r5_protobuf_source.rs`. UTF-16 archive validation is
covered by `crates/umf-core/tests/r5_protobuf_inspect.rs`, with the narrow
inspector changes in `crates/umf-core/src/protobuf_inspect.rs`. The focused
offline Rust commands use Rust/Cargo 1.90.0:

```sh
cargo test --locked --offline -p umf-core --test r5_protobuf_source
cargo test --locked --offline -p umf-core --test r5_protobuf_document
cargo test --locked --offline -p umf-core --test r5_protobuf_inspect
```

The pinned offline Rust 1.90.0 focused suites passed: `r5_protobuf_source` 8/8,
`r5_protobuf_document` 5/5, and `r5_protobuf_inspect` 9/9. The bounded source
tests cover JSON copy/shape/refusal order, duplicate keys and roots, serialized
JSON length including escaping, compiler callback controls and error
propagation, copy isolation, lone-surrogate source/identity values, descriptor
bounds and malformed compiler output. Source compilation remains an external
host capability; this slice adds no binding parity, browser execution, Edition
2024 compilation, source emission, or complete Protobuf semantics.

## Additive real native compiler callback run — 2026-10-23

The separate Rust integration harness
[`r5_protobuf_source_real_compiler.rs`](../../../../../../crates/umf-core/tests/r5_protobuf_source_real_compiler.rs)
now exercises the real `prepare_source_import` → trusted callback → finish path.
The callback writes only the supplied source map beneath a fresh temporary
directory, invokes the installed `protoc` executable with
`--include_imports --include_source_info --retain_options`, polls the child while
charging the same Rust `Context`, and returns its descriptor bytes and exact
compiler identity. On host-control refusal it terminates a running child or
reaps one that completed in the race, propagating the original control error
after successful cleanup. Production `umf-core` still does not start a process
or discover a compiler.

`/opt/homebrew/bin/protoc`; executable SHA-256 is
