# Stack dual licensing — 2026-10-18

The owner explicitly selected **MIT OR Apache-2.0**, at the recipient's option,
for the first-party UMF stack. This is the implemented licensing part of the
[Praxis lifecycle roadmap](../../01-frame/praxis-lifecycle-roadmap.md). It does
not implement that roadmap's remaining SDK, policy or lifecycle proposals.

## Changes and scope

UMF (this worktree), Weft, Truss, Ashlar, TableSpec and Hohfeld now have root
`LICENSE.md`, `LICENSE-MIT` and `LICENSE-APACHE` files. Existing Apache-only root
`LICENSE` files in Truss/TableSpec now explain the dual grant and contain both
texts. README statements agree. Each maintained first-party Python project's
`pyproject.toml` has the SPDX expression and explicit `license-files`; package
roots carry the texts so wheel/sdist builds can include them. Setuptools
minimums in Truss/Ashlar are raised to 77 for the PEP 639 metadata format.
First-party npm manifests and Weft Cargo package declarations are aligned too.

Maintained first-party Python, TypeScript/JavaScript, Rust, SQL, shell, C and CSS
sources receive SPDX headers with their shebangs/encoding declarations intact.
Generated output templates for both Python clients, the authored metamodel and
action producer identity emit headers on regeneration. Current generated
schema/constraint payloads were regenerated because the compiler/source digests
changed. Comparison with the previous payloads confirms identical semantics
apart from provenance and JSON Schema comments.

The SDK packager now copies all three license files into the archive and carries
`license` into its package metadata. The schema-browser packager copies the same
texts plus its retained `NOTICE`. The pre-existing Buf Technologies copyright
notice from that package's Apache text is retained in `NOTICE`.

Third-party dependencies, vendored/native oracle sources, upstream corpora,
datasets, frozen evidence, embedded runtime snapshots, generated distribution
archives and normative fixtures retain their own notices and custody. No
historical proof, external dataset license or already-published wheel is
relicensed by modifying its bytes. The header audit's explicit exclusions live
in `scripts/check-stack-licenses.py`; the root grant still covers first-party
material without requiring comments in JSON or binary formats.

## Publication and continuation

Ashlar and TableSpec licensing commits were published to their `main` branches
after the user explicitly approved publication. Both checkouts are clean and
match origin. Automatic review initially rejected publication without that
explicit approval; no rejected operation was bypassed.

UMF, Weft, Truss and Hohfeld remain local reviewable changes. No package-index
publication, public wheel replacement or release tag was performed. Existing
release artifacts keep their old metadata; issue new immutable package versions
when publishing rebuilt distributions. Requalify source-bound native certificates
before using these changed trees for new support claims.
