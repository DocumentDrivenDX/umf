## Delivered behavior

Binding layout resolution checks every Record/member, exact logical identity,
physical slot ownership, paired component order, domain/signedness, Key inventory,
index references and explicit directed foreign-key layouts. No unbound Field,
unknown relevant meaning or unsupported layout silently disappears. Public model
projections retain complete sources, explicit policy, all native paths and
residuals. Strict blocks unmet obligations; report emits a useful supported target
with those residuals. Recovery recomputes the complete report and exact artifact.

PostgreSQL/SQL Server emit all tables before constraints, expand every paired
Field into both Key/index/FK slots, enforce pair and composite-FK presence, exact
byte width, canonical text grammar/equality, allowed values and missing-value
literal defaults. SQL Server text uses Unicode storage and binary collation.
SQL Server publishes the seven required connection SET statements and emits
them before DDL. Native filtered uniqueness/reverse-cardinality probes allow
multiple absent rows, reject duplicate present/Nil references and refuse writes
with incompatible QUOTED_IDENTIFIER settings. Both dialects reject unsupported unsigned bigint pairs, unsafe/colliding names,
unsupported layouts and excessive key widths. Source participation/lifecycle
meaning that foreign keys cannot enforce remains explicit. Default-on-null
substitution is not mistaken for native SQL DEFAULT behavior.

Avro/Parquet emit complete Record bundles. Nullable pairs use one optional group
with two required exact64-bit members, avoiding independent-half nullability.
Avro accepts signed words; Parquet qualifies signed and unsigned words. Named
Avro value types have isolated namespaces. TableSpec emits native model documents
with an explicitly selected canonical UUID/hex string fallback, context-default
nullability and retained primary/alternate Key declarations. It refuses native
UUID/bytes/paired carriers rather than narrowing them to its signed32-bit INTEGER.

Complete-row APIs reject missing/extra/repeated Fields and slots before returning
anything. File datum APIs group paired slots and leave exact decimal/hex-to-native
conversion at the explicit driver boundary. These codecs are pure browser code;
they do not execute database writes or authorize independent-half updates.

## Retained limits and failed attempts

This qualified singular128-bit model profile does not silently widen mixed legacy
scalar/container/group, partition or general association layouts. Such composition
refuses pending separately qualified layouts. Native UUID and signed-pair index
order are not portable unsigned-byte order. File/model storage does not enforce
collection uniqueness, relationship existence/lifecycle, secondary indexes or
canonical string grammar. Text codec validation and explicit residuals remain
mandatory. Independent-half writers, other database isolation modes, Truss/Weft
adoption, physical cutover/rollback and performance optimality require their own
consumer/runtime evidence. No UUID generator is introduced.

Failed harness attempts were corrected without weakening production assertions:
prototype-sensitive Node comparisons were changed to compare JSON-safe values;
SQLCMD JSON display limits/options and right padding initially corrupted output;
large PRINT/hex catalog messages also truncated. A new filtered-index probe
exposed SQL Server's required connection settings; both public requirements and
generated DDL now declare them, and the native session-refusal control passes. Small framed Unicode chunks now
recover complete SQL Server catalog text, with every frame checked. A PostgreSQL
concurrency marker initially attached to the preceding UPDATE rather than the
actual sleeping statement; the barrier now checks the running statement. Spark
initially selected a different worker Python; driver/workers now use the same
explicit interpreter. fastavro UUID objects are normalized through the declared
text boundary. One new test attempted an empty allowedValues declaration that
core already forbids; the corrected test proves early refusal. An initial native
round-trip assertion incorrectly expected PostgreSQL's normal deparser to retain
layout; it now separately checks exact archived source and stable native export.
