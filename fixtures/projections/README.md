# JSON Schema-to-Protobuf projection evidence

`constraints.schema.json` is an original UMF fixture authored 2026-09-20. It combines
required members, bounds, an annotation default, nullable strings, array length and
uniqueness, string alternatives and a number. The existing original Order fixture
adds nested referenced objects; tests also exercise a recursive definition.

`constraints-result.json` is generated by the projection test and includes source,
explicit field bindings/integer policy, generated target source, target UMF, mappings
and issues. Source recovery uses the retained source document. Target-only descriptor
reimport is deliberately separate and cannot reproduce the JSON Schema payload.

`oracle-results.json` records nine explicit source/target instance comparisons and
three additional native checks. Python jsonschema validates source instances;
protoc 36.2 and Python protobuf 7.36.2 validate native target behavior. The vectors
are manually specified correspondences, not evidence for a general instance converter.
Every observed mismatch must have its expected code/path in the actual projection
report. Removing the required-member disclosure causes the oracle to fail.

Known differences include unenforced required/minimum/minLength/uniqueItems/minItems/
oneOf, rejection of source-valid out-of-range integers and distinct null, native
default behavior, absent/empty repeated fields and non-finite native doubles.
The profile also reports native UTF-8/ProtoJSON encoding, object openness, annotations
and source identity limitations. Unsupported scopes/types and invalid bindings block.

The report's complete structural JSON Schema lives in
`spec/projections/json-schema-protobuf.schema.json` and references the core schema.
Shape validation is supplementary; the independent native expectations determine
whether the report is honest. Chromium exercises the public projection API and WASM
compiler while checking source retention and target-only separation.

Support scope: Draft 2020-12 explicitly typed object schemas to proto3 under
CONTRACT-004. Complex references, arbitrary unions and data conversion remain outside
this profile. This is directed lossy projection, not native semantic equivalence.
