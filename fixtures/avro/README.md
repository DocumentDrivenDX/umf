# Avro authored evidence

`order.avsc` is an original UMF fixture, not an Apache conformance corpus.
`round-trip.avsc` is generated by `bun test tests/avro`.
`scripts/avro-oracle.py` generates `oracle-results.json` using pinned Apache Avro
1.12.0 and fastavro 1.12.2. It compares full metadata, binary bytes and decoded
values, exercises reader defaults, rejects invalid data and detects a changed
default. The report records that fastavro's strict writer accepts an out-of-range
int that Apache rejects. Strict fastavro encoding is intentional: its default
convenience behavior may supply omitted fields.

`upstream/manifest.json` pins Apache Avro release-1.12.0 commit
`8c27801dc8d42ccc00997f25c0b8f45f8d4a233e`, SHA-256 hashes, selection directories
and all 20 schema files. Apache LICENSE and NOTICE accompany the unchanged files.
Selection includes every `.avsc` in the three listed directories, without filtering
by outcomes. `corpus-results.json` records native exports and browser diagnostics;
`corpus-oracle-results.json` records independent native parsing and binary probes.
Run `bun test tests/avro` before `.venv/bin/python scripts/avro-corpus-oracle.py`.
Both steps are included in `bun run test:conformance`.

All 20 retain metadata; 12 are fully interpreted by the browser profile. Apache
and fastavro accept 19 standalone schemas; ApplicationEvent references an external
DocumentInfo definition. One generated finite datum for each of those 19 schemas
preserves bytes and values through Apache encoding/decoding. This is not exhaustive
instance or language conformance. The shared interop schema exercises all primitive
carriers plus enum, fixed, nested collections, unions and recursive names.

RPC, IDL, implicit external schema discovery, container files and cross-system transforms
remain open. See CONTRACT-007 for the browser interpretation subset.


`dependency-bundle.json` supplies DocumentInfo explicitly before ApplicationEvent,
including an edited dependency. `scripts/avro-dependency-oracle.py` uses independent
Apache/fastavro name registries and checks original round-trip bytes, edited bytes
values and rejection of stale string data. `dependency-oracle-results.json` records
those results. The standalone corpus deliberately continues testing missing names;
bundle evidence is a separate, stronger input configuration.


`document-projection.json` contains the explicit Avro-to-JSON-Schema projection and
an authored JSON instance. `scripts/avro-projection-oracle.py` compares five manually
mapped native/target instances and proves that deleting the long-range issue fails
the fidelity check. `projection-corpus-results.json` records all 20 official schema
projection outcomes: 19 generated targets compile, and the unresolved standalone
ApplicationEvent is blocked. These schemas do not convert arbitrary instance data
or restore Avro identity, union tags, binary encodings or reader-resolution rules.
