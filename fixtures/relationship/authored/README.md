# Authored relationship shape corpus

`corpus.json` is generated by `bun scripts/relationship/authored-corpus.ts`.
Its `base` is a UMF 0.6.0 Key-candidate document with nine Records, exclusive
`Record.members` field ownership and stable named Keys. It passed the committed
Key candidate's `validateDocument` check at `b73976bf`; that validation is
for the base only. `cases` are separate CONTRACT-041 relationship proposals,
not members of a published core envelope yet.

The eight cases cover one-to-one, owned Order→Line one-to-many, many-to-one
through Customer's alternate `account` Key, many-to-many, a heterogeneous
source set, self-reference, undirected association, and a Student/Course
association represented by a
separately keyed Enrollment Record with its own `grade` field. Each proposal
names exact element IDs and an exact target Key ID. The relationship core bead
will migrate this corpus to the accepted envelope, validate it, and add the
ideal/native recovery and residual fixtures. This preparatory corpus is not
FR-3 admission or five-system delivery evidence.
